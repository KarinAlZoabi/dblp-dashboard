FRONTEND CHAT SESSION PATCH
===========================

Your backend now returns a `session_id`. The React chatbot only needs to keep it
and send it back with the next message.

1) In Chatbot.jsx, add state near your other useState calls:

    const [sessionId, setSessionId] = useState(null);

2) Change the RAG call from:

    const response = await askRagChat(cleanedQuestion, 5);

   to:

    const response = await askRagChat(
      cleanedQuestion,
      5,
      sessionId
    );

3) Immediately after:

    const data = response.data;

   add:

    if (data.session_id) {
      setSessionId(data.session_id);
    }

4) In your api.js, change askRagChat to:

    export const askRagChat = (
      question,
      topK = 5,
      sessionId = null
    ) =>
      axios.post(`${API_URL}/api/rag/chat`, {
        question,
        top_k: topK,
        session_id: sessionId
      });

That is all the frontend needs for multi-turn memory.
