IMPORTANT: THE SCREENSHOT SHOWS THAT THE FRONTEND IS NOT REUSING THE SAME SESSION.

The backend conversation memory only works when every turn sends back the
`session_id` returned by the previous /api/rag/chat response.

Use a ref so there is no stale React-state timing problem.

Chatbot.jsx
-----------

1. Change the React import to include useRef if it does not already:

    import { useEffect, useRef, useState } from "react";

2. Near your other state/ref declarations add:

    const sessionIdRef = useRef(null);

3. Call the API like this:

    const response = await askRagChat(
      cleanedQuestion,
      5,
      sessionIdRef.current
    );

    const data = response.data;

    if (data.session_id) {
      sessionIdRef.current = data.session_id;
    }

4. For debugging temporarily add:

    console.log("RAG session:", sessionIdRef.current);

api.js
------

Make sure askRagChat REALLY accepts and sends the third argument:

    export const askRagChat = (
      question,
      topK = 5,
      sessionId = null
    ) =>
      axios.post(`${API_URL}/api/rag/chat`, {
        question,
        top_k: topK,
        session_id: sessionId
      });

Browser check
-------------

Open DevTools -> Network -> /api/rag/chat.

First request:
    session_id: null

First response:
    "session_id": "<some id>"

Second request MUST contain exactly that same id:
    "session_id": "<same id>"

If the second request says null, conversation memory cannot work.
